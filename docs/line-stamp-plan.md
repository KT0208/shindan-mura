# 診断村 LINEスタンプ制作プラン

## 基本方針

- 1診断につき2種類、全27診断で54個を制作する。
- Aは診断の個性や世界観が伝わる「キャラクタースタンプ」。
- Bは日常のLINEで使いやすい「リアクションスタンプ」。
- 既存の診断キャラクターの顔、色、モチーフを保ち、表情とポーズでセリフを表現する。
- 文字は小さく表示しても読める太さと短さにする。
- 画像は背景透過、文字とキャラの縁に白フチを付ける。

## 画像制作時の共通レイアウト

- キャンバスは正方形で制作し、LINEスタンプ用の横長領域に縮小しても見切れない中央構図にする。
- キャラクターは画面の55〜70%、セリフは画面上部または空いた側に置く。
- セリフの誤字を防ぐため、生成後に文字の視認確認を必ず行う。
- 影、背景色、写真的な質感、ロゴ、透かしは入れない。
