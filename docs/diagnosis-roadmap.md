## 🎨 制作キュー(次に作る順)

**方針(2026-10-14 決定):お金カテゴリの強化。** お金=1本しかなく、検索価値・広告単価・既存A8案件(証券/クレカ/ポイ活/占い)との相性が高いため、1→5本に増やす「お金診断シリーズ」を優先する。一気に出さず2〜3週に1本ペース、シリーズ内で相互リンク。

### お金診断シリーズ(看板=総合診断、他は狭い切り口でズラす)
モチーフは**オリジナル生物「銭さししっぽ(ぜにさしっぽ)」**＝もふもふ生物＋尻尾がコインの束。尻尾のコイン量で貯める⇄使うを表現。シリーズで同じ生物ファミリーにしてブランド化。

| 軸 | 診断 | 状態 |
|---|---|---|
| 運 | 金運タイプ診断 | ✅ 公開済み(money-luck) |
| **総合(看板)** | **お金の使い方診断**(spending-type、銭さししっぽ) | ✅ **制作完了・公開準備OK(2026-10-14、アップ待ち)** |
| ポイ活/節約 特化 | (狭い切り口に要再設計) | 📋 候補 |
| 投資・増やす 特化 | 投資スタイル診断 | 📋 候補 |
| ギャンブル/一発 | ギャンブル度診断 など | 📋 候補 |

お金の使い方診断の16タイプ(浪費度 低→高・銭さししっぽ): ゴールド貯金/コツコツ積立/計画キッチリ/投資チャレンジ/のんびり資産形成/お金の不安が大きい/ときめき優先/お金ほったらかし/体験・旅行派/食費かさみ/お買い物大好き/サブスク沼/見栄はり散財/美容に全力/金欠ぐったり/宵越しの金なし。
※貯金体質・金銭感覚は総合診断とかぶるため保留。他4本はもっと狭い切り口に再設計する。

## 制作フロー(1本あたり)

1. テーマ・16タイプのコンセプト確定
2. キャラ16体の画像用意(`new-characters/{テーマ}/` に 1〜16.png)
3. 背景除去→webp化(full `characters/{basePath}/` + small `characters-small/{basePath}/`) — 詳細は `character-image-pipeline` メモ
4. データ日英生成(characterData(.en)/packs/resultDetails(.en)/diagnosisData(.en))
5. `npm run build` で `/diagnosis/{id}/` 静的ページ・sitemap も自動生成
6. 公開(hidden外す)→ dist ZIP(line-stamps と api/topics.php 除外)→ 手動アップ
7. **このMAPを更新**
