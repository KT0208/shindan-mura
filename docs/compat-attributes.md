# 全キャラ相性診断：属性設計

全36診断・576体の住人どうしの相性を出すための共通属性。
データ本体は `src/compat/characterAttributes.js`。

## 属性は4つ（コード4文字）

| 軸 | 記号 | 意味 |
|---|---|---|
| テンポ | **D 動** / **S 静** | すぐ動く ／ じっくり構える |
| 判断 | **J 情** / **R 理** | 気持ちで決める ／ 頭で決める |
| 距離 | **K 攻** / **M 守** | 自分から近づく ／ 来るのを受け止める・距離を保つ |
| 元素 | **F 火** / **W 水** / **A 風** / **E 土** | 情熱 ／ 感受性・寄り添い ／ 自由・軽やか ／ 安定・誠実 |

例：`DJKF` = 動・情・攻・火（ペンライト妖精、推し一筋ドラゴンなど）

性格3軸の組み合わせ（ベースタイプ）は 8 種、元素は 4 種。

## 相性の出し方

相性文はキャラごとではなく **部品の組み合わせ** で作る。

1. **元素の相性**（4×4 → 10 通り）… 2人の関係の「空気感」
   - 火×風 / 水×土 = ◎ 高め合う・育て合う
   - 同じ元素 = ○ 言わなくても分かる
   - 火×土 / 水×風 = ○ 補い合う
   - 火×水 / 風×土 = △ ぶつかるけど刺激になる
2. **性格軸の相性**（8×8 → 36 通り）… 「2人の間で起きること」
   - 軸ごとに「同じ＝共感」「違う＝補完」のパターン文を用意する
   - 例：攻×守 → 「片方が誘って片方が乗る、自然な役割分担」
3. **2体の名前・役割（role）を差し込む** … ペアごとの個性

書く文章量の目安：元素 10 本 + 性格 36 本 = **46 本**。これで約 16 万ペアすべてに結果が出せる。

## スコア（案）

- 元素：◎ 40 / ○ 30 / △ 20
- 性格3軸：一致は「共感」、違いは「補完」としてどちらも +10（文章で意味を変える）
- 同じ診断の2体（同じ村の仲間）+10
- 最終値は 60〜99% に収める（低すぎるスコアはシェアされにくい）

## 分布（2026-11-24 時点）

- 元素：火 118 / 水 155 / 風 144 / 土 159
- テンポ：動 249 / 静 327、判断：情 347 / 理 229、距離：攻 281 / 守 295
- ベースタイプで少ないのは 動・理・守（DRM 9体）と 動・情・守（DJM 24体）。
  キャラの性質どおりの偏りなので、そのままにしている。
