# 鑑定村 コンテンツ追加のアイデア

鑑定村のコンセプト:「数」と「日本の神社・お寺の文化」で占う、スピリチュアルな占いの村(6言語)。
新しい鑑定を足すときは、解説記事(読み物)もセットで作る(検索流入とアドセンス審査に効く)。

## A. すぐ作れる(今の仕組みを使い回せる)

| 鑑定 | 内容 | 使い回すもの |
| --- | --- | --- |
| 縁結びおみくじ | 恋愛だけに絞ったおみくじ。「待人」「縁談」「相性の良い人」など | おみくじの演出 |
| 金運おみくじ | お金に絞ったおみくじ。「商売」「くじ運」「使ってよい日」など | おみくじの演出 |
| 数秘チャート | 運命数に加えて、誕生数・表現数・ハートナンバーなどを一覧にした詳しい鑑定 | 数秘術の計算 |
| 今月の運勢 | 個人月数(パーソナルマンス)から今月のテーマ | 数秘術の計算 |

## B. 日本・東アジアの文化の鑑定(外国の人にも人気が出やすい)

| 鑑定 | 内容 | メモ |
| --- | --- | --- |
| 守り本尊鑑定 | 生まれ年の干支から、一生守ってくれる仏様(千手観音・不動明王など8尊)を出す | 実際にお寺で使われる考え方。お守り・お参りの記事とつながる |
| 九星気学(本命星) | 生まれ年から一白水星〜九紫火星を出し、性格と今年の運勢を出す | 中国・台湾・韓国でもなじみがある。節分(2/4ごろ)で年が切り替わる点に注意 |
| 干支の性格 | 十二支ごとの性格と相性 | 中国語・韓国語の人に特に人気 |

## C. シェアされやすい鑑定

| 鑑定 | 内容 |
| --- | --- |
| 前世鑑定 | 生年月日から「前世の職業・国・時代」をストーリー仕立てで出す |
| タロット1枚引き | 大アルカナ22枚から1枚。カードの絵は図形で描く |

## D. 検索から人が来る大きな企画(作る量は多い)

| 企画 | 内容 |
| --- | --- |
| 誕生日の花・誕生石・誕生色 | 366日分のページ。「○月○日 誕生花」で検索から人が来る |
| 今日は何の日(六曜・吉日カレンダー) | 大安・仏滅、一粒万倍日・天赦日など。暦の計算が必要 |

## おすすめの順番

1. 縁結びおみくじ・金運おみくじ(おみくじが人気なら、すぐ横に広げられる)
2. 守り本尊鑑定(日本文化 × スピリチュアルで鑑定村らしい)
3. 九星気学(毎年「今年の運勢」で人が戻ってくる)
4. 前世鑑定(SNSでシェアされやすい)

アナリティクスで「おみくじ」「誕生日鑑定」などのどれがよく使われているかを見てから、順番を決め直す。

## E. 西洋の占い

| 鑑定 | 内容 | 作りやすさ・メモ |
| --- | --- | --- |
| エンジェルナンバー | 111・222・777 など、よく目にする数字の意味 | ◎ 数秘術と相性が良い。000〜999のページで検索から人が来る。世界中で人気 |
| 生まれた日の月の形 | 誕生日の月の満ち欠け(新月・満月など8種類)で性格を読む | ◎ 日付だけで計算できる。月のイラストがきれいに描ける |
| タロット1枚引き | 大アルカナ22枚から1枚。カードをめくる演出 | ○ カードの絵は図形で描く |
| ルーン占い | 北欧の24文字の石から1つ引く | ○ 石を引く演出 |
| 振り子(ペンデュラム) | 質問を思い浮かべると、振り子がYes/Noを示す | ○ おみくじのような演出で遊べる |
| ケルトの樹木暦 | 誕生日から13本の木のどれかを出す | ◎ 日付だけで出せる |
| 星座(太陽星座)をくわしく | 今は星座名だけ表示。性格・相性・今月の運勢まで出す | ○ |
| ホロスコープ・月星座 | 生まれた時間と場所が必要 | △ 計算が重く、入力も増える。後回し |
